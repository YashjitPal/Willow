# assets/voices/ — Preview audio files for voice selection

Drop voice preview audio files here (e.g. `.mp3`, `.wav`, `.m4a`, `.ogg`, `.aac`).

## File Naming Convention

Name preview audio files using the voice ID or voice name (case-insensitive):
- `Zephyr.mp3` or `zephyr.mp3`
- `Puck.mp3` or `puck.mp3`
- `Charon.mp3` or `charon.mp3`
- `Kore.mp3` or `kore.mp3`
- etc.

When a user selects a voice in Voice Settings, Willow looks up and plays the corresponding preview audio file from this directory.
